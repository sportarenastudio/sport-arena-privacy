Suppression de compte

Sport Arena — Sport Arena Studio

Demander la suppression de votre compte

```

Si vous souhaitez supprimer votre compte Sport Arena ainsi que les données personnelles et données de jeu qui y sont associées, vous pouvez effectuer une demande de suppression en contactant notre équipe.

La demande de suppression peut être effectuée sans avoir à réinstaller l'application Sport Arena.

Demander la suppression de mon compte
```

Informations à fournir

```

Afin que nous puissions identifier votre compte et traiter votre demande, veuillez indiquer dans votre e-mail :

  • l'adresse e-mail associée à votre compte Sport Arena ;
  • votre pseudonyme Sport Arena, si vous le connaissez ;
  • toute autre information permettant d'identifier votre compte.

Nous pouvons demander des informations supplémentaires raisonnables afin de vérifier que la demande provient bien du propriétaire du compte.

```

Quelles données seront supprimées ?

```

Après vérification de la demande, les données associées à votre compte Sport Arena seront supprimées conformément à notre politique de confidentialité.

Cela peut notamment inclure :

  • les informations de votre compte ;
  • votre profil et votre pseudonyme ;
  • vos statistiques et votre progression ;
  • vos trophées et données de classement ;
  • vos données liées aux clans, quêtes et défis ;
  • vos données de personnalisation et inventaire ;
  • les autres données personnelles associées à votre compte.
```

Données pouvant être conservées

```

Dans certaines circonstances limitées, certaines informations peuvent devoir être conservées pendant une période supplémentaire lorsque cela est nécessaire pour respecter une obligation légale, assurer la sécurité du service, prévenir les fraudes ou résoudre un litige.

Toute conservation de ce type est limitée à ce qui est nécessaire et applicable.

```

Délai de traitement

```

Nous traiterons les demandes de suppression dans un délai raisonnable après vérification de l'identité du demandeur.

Si des informations supplémentaires sont nécessaires pour traiter la demande, nous vous contacterons à l'adresse e-mail fournie.

```
